Reasoning

How the traits file is derived

The source of truth is the PPO ontology hosted on GitHub main. The refresh workflow downloads the ontology, snapshots the exact source version under reasoning/<version>/ppo.owl, and regenerates the trait lookup table. 

python3 reasoning/refresh_traits.py

The output includes:

  • data/traits.csv
  • reasoning/traits_build_metadata.json
  • docs/traits-data.json

Ingest Procedure

Recommended sequence for a new data release

  1. Refresh the PPO-based trait mapping with python3 reasoning/refresh_traits.py.
  2. Review the ontology version and diff data/traits.csv.
  3. Place release CSV files under the appropriate data directory and add transform.yaml if normalization is needed.
  4. Dry-run ingestion with python3 loader.py --mode=<mode> --test ....
  5. Run the real load with python3 loader.py --mode=<mode> --no-drop-existing ... or rebuild from scratch if required.
  6. Use python3 update_decade_start.py --wait if the live index needs the derived decadeStart field backfilled.
  7. Export or inspect the live datastore with python3 download_csv_dump.py when you need a post-load verification sample or full dump.
