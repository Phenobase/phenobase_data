Reasoning

Start here for every release

The source of truth is the PPO ontology hosted on GitHub main. The refresh workflow downloads the ontology, snapshots the exact version under reasoning/<version>/ppo.owl, regenerates data/traits.csv, and publishes the Pages viewer artifacts. 

python3 reasoning/refresh_traits.py

Generated outputs:

  • data/traits.csv
  • docs/traits.csv
  • reasoning/traits_build_metadata.json
  • docs/traits-data.json

Ingest Procedure

Recommended sequence for a new data release

  1. Refresh the PPO-based trait mapping with python3 reasoning/refresh_traits.py.
  2. Review the ontology version and diff data/traits.csv.
  3. Prepare the source dataset directory and optional transform.yaml.
  4. Dry-run ingestion with python3 loader.py --mode=<mode> --test ....
  5. Review loading_errors.csv and fix transform or source-data issues.
  6. Run the real load with python3 loader.py --mode=<mode> --no-drop-existing ....
  7. Use python3 update_decade_start.py --wait if the live index needs decadeStart backfilled.
  8. Export or inspect the live datastore with python3 download_csv_dump.py if needed.

Loading

Main ingest command

The loader validates required fields using data/columns.csv, expands trait mappings through data/traits.csv, and bulk indexes into Elasticsearch. 

python3 loader.py --mode=<machine|in_situ|herbarium> --test --no-drop-existing <data_dir>

Utilities

Export and maintenance helpers

  • python3 download_csv_dump.py for live API CSV exports
  • python3 update_decade_start.py --wait for live index backfills
